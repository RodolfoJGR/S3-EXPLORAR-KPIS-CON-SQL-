# S3-EXPLORAR-KPIS-CON-SQL-
Análisis del desempeño financiero con SQL - Resumen ejecutivo


## 📊 Descripción
Este proyecto se centra en el **análisis del desempeño financiero de diferentes países** utilizando SQL y hojas de cálculo.  
El objetivo principal es evaluar ingresos, costos, campañas de marketing y métricas clave como **Margen de utilidad** y **ROI** para identificar oportunidades de mejora en la estrategia de inversión.

---

## 🛠️ Tecnologías utilizadas
- **SQL**: consultas para extracción y análisis de datos.  
- **Excel / Google Sheets**: construcción de dashboards y reportes ejecutivos.  
- **Visualizaciones**: tablas comparativas y gráficos de desempeño financiero.  

---

## 🚀 Funcionalidades
- Consolidación de métricas financieras por país.  
- Cálculo de indicadores clave:
  - **Margen (%)**: proporción de beneficio bruto respecto a ingresos.  
  - **ROI (%)**: rentabilidad de las campañas de marketing.  
- Identificación de países con ROI bajo y margen estable.  
- Simulación de escenarios (ej. aumento del gasto en campañas).

## 📈 Hallazgos principales
- **Estados Unidos**: ROI alto debido a costos de campaña relativamente bajos y beneficios elevados.  
- **Canadá y Europa**: ROI bajo por campañas demasiado costosas, aunque el margen de utilidad se mantiene estable (~40-45%).  
- **Insight clave**: replicar la estrategia de Estados Unidos en países con ROI bajo para mejorar la eficiencia.
